# 提醒与推送渠道配置

CFNote 的提醒分两层:

1. **应用内提醒**——给笔记设提醒时间后,到期会在顶栏铃铛按「已到期 / 即将到期」提示(打开应用即可见)。
2. **渠道推送**(本页重点)——到期后额外把提醒推送到企业微信 / 飞书 / 钉钉 / 个人微信(Server酱)/ Telegram / 自定义 Webhook,推到手机。

系统每 **5 分钟**扫描一次到期未推送的提醒,所以推送最迟在设定时间后约 5 分钟内送达。推送消息包含笔记标题和一个打开链接(打开链接用你保存配置时自动记录的站点地址)。

---

## 一、给笔记设提醒

在笔记编辑器顶栏点「提醒」→ 选预设(今晚 20:00 / 明天 09:00 / 下周 09:00)或用「自定义时间」选一个具体时刻 → 顶栏铃铛随即出现。要取消,再次打开点「清除提醒」。到期后铃铛显示红色数字徽标,点开可打开笔记或点「完成」清除。

> 只设提醒、不配任何渠道,也能用应用内铃铛;渠道推送是额外的手机通知。

---

## 二、配置推送渠道

进入 **设置(顶栏齿轮)→ 通知渠道 / 提醒推送**。点下方虚线按钮添加一个渠道,填好字段后点该渠道的「**测试**」按钮,收到「✅ CFNote 测试消息」即成功,最后点右下角「**保存**」。

多个渠道可同时启用;临时停用某个取消其勾选即可(配置保留)。所有 token/webhook 存在服务端设置中,**导出备份时会自动排除**。

### 企业微信(推荐,国内直达)

1. 需要一个企业微信组织(个人可在 work.weixin.qq.com 免费注册一个只有自己的企业)。
2. 在企业微信里进入任一群 → 右上角「···」→ **群机器人** → **添加机器人** → 新建。
3. 复制它的 **Webhook 地址**(形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx`)。
4. 面板点「+ 企业微信」,把地址粘到 **群机器人 Webhook 地址**。

### 飞书

1. 飞书群 → 设置 → **群机器人** → 添加机器人 → **自定义机器人 / Custom Bot**。
2. 复制 **Webhook 地址**(形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`)。
3. 若在飞书侧勾选了**签名校验**,把它给的密钥填到「**签名密钥**」字段;没开就留空。

### 钉钉

1. 钉钉群 → 群设置 → **智能群助手** → 添加机器人 → **自定义**。
2. 安全设置建议选「**加签**」,复制它给的加签密钥(`SEC` 开头)。
3. 复制 **Webhook 地址**(形如 `https://oapi.dingtalk.com/robot/send?access_token=xxxx`)。
4. 面板里 Webhook 填「Webhook 地址」,密钥填「**加签密钥**」字段。
   - 若你在钉钉侧改用「自定义关键词」而非加签,则加签密钥留空,并把关键词设为「**提醒**」(推送消息标题含「提醒」二字即可通过)。

### 个人微信(Server酱)

1. 打开 [sct.ftqq.com](https://sct.ftqq.com),微信扫码登录,按提示关注它的公众号。
2. 在「Key & QQ」页复制 **SENDKEY**(`SCT` 开头)。
3. 面板点「+ 个人微信(Server酱)」,填到 **SENDKEY** 字段。消息会由该公众号推送到你的微信。

### Telegram

1. 在 Telegram 找 [@BotFather](https://t.me/BotFather),发 `/newbot` 建一个 bot,拿到 **Bot Token**。
2. 给你的新 bot 随便发一条消息,再找 [@userinfobot](https://t.me/userinfobot) 获取你的 **Chat ID**(纯数字)。
3. 面板分别填 **Bot Token** 和 **Chat ID**。
   > 注意:国内接收 Telegram 消息需要科学上网。

### 自定义 Webhook

任何能接收 JSON 的服务都行——面板填一个 URL,系统会原样 `POST {title, body, url}`。可用于对接 Bark、ntfy、PushPlus 等,或你自己的服务。

---

## 三、工作原理(简要)

- 配置以 JSON 存在服务端 `settings.notify_channels`;保存时同时记录站点地址 `site_url`(取当前浏览器地址,用于推送里的深链)。
- 每 5 分钟的 Cron 扫描 `remind_at` 已到期、`reminded_at` 为空、未删除的笔记,逐条推送到所有**已启用**渠道,发送后写入 `reminded_at` 防止重复推送。
- 在笔记上重新设置或修改提醒时间会清空 `reminded_at`,即「重新武装」,到点会再次推送。
- 移入回收站的笔记会清空提醒,不再推送。
- 钉钉 / 飞书的加签用 Web Crypto 的 HMAC-SHA256 在服务端计算。
- 发送失败会记入系统日志(顶栏「系统日志」可查),但仍标记为已推送以避免每 5 分钟刷屏重发。

## 四、渠道选择说明

企业微信 / 飞书 / 钉钉的「群自定义机器人」本质都是一个入站 Webhook,**无需自有域名、无需审核**,国内可直接收到,最推荐。个人微信没有简单官方接口,经 Server酱这类第三方公众号中转。QQ 官方机器人需要审核、第三方方案要自建常驻客户端,与本项目的 Serverless 无状态模型冲突,未做内置渠道;确有需要可经「自定义 Webhook」对接第三方中转服务。

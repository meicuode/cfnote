# 生产验证核对表

**活文档，覆盖到 P16.6。** 这份表把 P13.7 → P16.6 共 10 批积压的验证点合并成一次能跑完的流程。

## 为什么要有这份表

积压到第 10 批的时候，最贵的不是"没验"，是**故障定位会归错帐**。P16.1 / P16.5 系列动了笔记本结构和可见性，P14.1 / P14.2 动了删除语义和备份——如果 P14.1 的删除语义其实有问题，症状现在会以"私密笔记本表现怪"的形式出现，而人会往最近那批上找。一次验完，锅才落得准。

## 这份表**不**验什么

**已被自动化测试覆盖的一律不进。** 回收站语义、备份导出导入往返、私密不变式的四条写入路径、限流窗口算术、单页不进文章流、slug 路由注册——这些在 workerd + 真 D1 + 真 R2 里跑过（`tests/worker/`，见 `README.md`「测试」一节），手点一遍只是重复劳动。

留在这里的只有测试**够不着**的三类：

| 类别 | 为什么测不到 |
|---|---|
| 真浏览器行为 | 文件选择、拖拽、右键落点、窄屏布局——没有 `@testing-library/react`，`FileList` 的活引用行为更是只有 Blink 里才有 |
| 真绑定 | Vectorize / Workers AI / Cache API / R2 + cron——`wrangler.test.toml` 刻意不声明它们（无本地实现） |
| 真部署配置 | `run_worker_first`、预渲染 HTML、`[assets]`——测试配置刻意不声明 `[assets]`，否则测试就依赖 `dist/` 构建产物 |

## 用法

- 生产地址 `https://cfnote.zuichu.de`，**先硬刷新**（Ctrl+Shift+R）。
- 第 0 步建一个专用笔记本，全程在它里面做，最后整本删掉——**不要拿真实笔记验**。
- 需要"访客视角"的地方一律开**无痕窗口**。自己登录着看什么都正常，这正是 P14.2 那个 bug 藏得住的原因。
- ⚠️ 标记的项有副作用，看清楚再做。
- 每项后面的 `(Pxx)` 是它覆盖的批次，出问题时照这个去 `DESIGN.md` §10 查当初的设计意图。

## 0. 准备

- [ ] 建笔记本 `验证-YYYYMMDD`，在它下面再建两个子笔记本 `子A`、`子B`。（顺带就验了 P16.1 的建子本）

## A. 部署本身活着（这层坏了后面全白验）

- [ ] **1.** 打开站点硬刷新：侧栏出得来、点开一篇笔记正文能加载。去「设置 → 系统日志」看有没有新的红条。 `(全部)`

## B. 保存与编辑

- [ ] **2.** 新建一篇笔记，打一行字，**在打完最后一个字的 3 秒内连按 Ctrl+S 三次** → 列表里只多出**一篇**。
  > 这是 P15.3 的原始复现路径。主犯是自动保存定时器（打完字排下 3 秒倒计时）而不是 Ctrl+S 本身，所以**必须在 3 秒内按**，等久了测不出来。 `(P15.3)`
- [ ] **3.** DevTools 切 Offline，改动这篇笔记 → 状态栏走到「保存失败，点『保存』重试」并**停下来**（不再每 3 秒打接口，看 Network 面板确认）。恢复网络，改一个字 → 重试额度归零，能存上。 `(P15.3)`

## C. 导入

- [ ] **4.** 「导入」选一个**含子目录**的本地文件夹 → 不再报「所选内容中没有 .md / .markdown / .txt 文件」；导进来后**子目录里的文档标题带相对路径**（`子目录/文件名`），根目录下的仍只有文件名。 `(P15.4)`
- [ ] **5.** 再选**单个 .md 文件**导入 → 也能进（同一个 `FileList` 活引用 bug 会同时影响单选）。导完在搜索框搜这篇的正文关键词 → **能搜到**。
  > 后半句验的是 Vectorize + Workers AI 绑定在生产真的通——本地测试环境根本没有这两个绑定。 `(P15.4 / 绑定)`

## D. 笔记本树

- [ ] **6.** 把 `子B` 拖到 `子A` 下面（三层）；再试着把 `子A` 拖进 `子B` → **应被拒**（环检测）。然后把一篇笔记从 `子A` 拖到 `子B` → 两本的数字**一增一减**。
  > 数字那半句是 P16.6 的 `article_count` 重算。以前是 `±1` 增量写，漏一次就永久歪；现在是重算，所以哪怕歪了下一次写入也会自己纠正。 `(P16.1 / P16.6)`
- [ ] **7.** `子A` 有子本时删 `子A` → 右键「删除」置灰或提示「请先删除或移走它的子笔记本」。 `(P16.1)`

## E. 私密笔记本（最需要人验：涉及"别人看得见什么"）

- [ ] **8.** 在 `子A` 里放一篇笔记并**发布到博客**，复制博客地址，**用无痕窗口确认能打开**。回来把 `子A` 设为私密 → 弹框应写明「N 篇，其中 1 篇已发布」；确认后回无痕窗口刷新那个地址 → **应当 404**。 `(P16.5 / P16.5.1)`
- [ ] **9.** 看侧栏图标：`子A` 是**实色锁**，它下面的 `子B` 是**淡色锁**（继承）；点 `子B` 的私密开关应是置灰的「已随上级私密」。笔记本自己设的**颜色**仍在书本图标上。 `(P16.5.1 / P16.5.2)`
- [ ] **10.** 取消 `子A` 的私密 → 弹框说明「已有的仍保持私有，变的是以后新写的」；确认后侧栏锁消失，但点进那几篇笔记**仍然带私有标记**，且第 8 步那个博客地址**仍然 404**。 `(P16.5.2)`
- [ ] **11.** ⚠️ 这条要按顺序做，验的是 P16.5.3 修的绕过路径：在 `子B` 放一篇笔记并**发布**，然后**先删掉它**（进回收站），**再**把 `子B` 设为私密，**最后**从回收站恢复它 → 恢复回来的这篇**必须是私有的**。
  > 恢复回来是"未私有"就说明回收站这条绕过路径又通了。 `(P16.5.3)`

## F. 文件管理（纯浏览器行为，测不到）

- [ ] **12.** 上传三四个附件。单击独选 / Ctrl 点选 / Shift 连选 / Ctrl+A 全选 / Esc 清空 / 双击打开，各试一遍；底部状态栏的选中数对得上。 `(P13.7)`
- [ ] **13.** 在**紧贴屏幕右下角**的那一行上右键 → 菜单**不超出屏幕**（会自动往左上翻），能点到「删除」。右键一个未选中的行 → 选择替换成它；右键选中集里的行 → 整段保持。 `(P13.8)`
- [ ] **14.** 拖拽移动：「拖到此处移出文件夹」那块**只在拖拽进行中出现**（不拖时、切目录后都不该挂着）。 `(P13.7)`
- [ ] **15.** 把一个**正被已公开笔记引用**的附件拖进私密文件夹 → 应先弹**只读预检**、列出受影响的公开文章，确认后才真的移动。 `(P14.2)`

## G. 博客与评论

- [ ] **16.** 博客地址形如 `/blog/12/标题-slug`；把 `/blog/12`（不带 slug）直接打开**也能出内容**；改一次标题后**老地址不断**。用无痕窗口看详情页**右键→查看源代码**，`<title>`、`og:` 卡片、正文文字应当**直接在 HTML 里**（不是靠 JS 拉回来的）。
  > 后半句验预渲染。测试配置刻意不声明 `[assets]`，所以预渲染出来的 HTML 与 canonical 在本地一行都测不到。 `(P15.2 / 部署配置)`
- [ ] **17.** 无痕窗口发一条评论，正文写 `**粗** *斜* ~~删~~ [链接](https://example.com)` 再插一个表情 → 渲染正确，链接带 `nofollow`（查看源代码确认）。**紧接着再发一条** → 被「评论太频繁」挡住。
  > 后半句是 P16.6 换了限流实现之后的行为回归——行为该和以前完全一样。 `(P13.9 / P16.6)`
- [ ] **18.** 后台「博客管理 → 评论管理」：刚那条评论在列表里应显示为**纯文本**（`**粗**` 就该显示成 `**粗**`），能看到来源 IP 与 UA；鼠标悬浮出灰底，点「回复」出绿底且两种状态**互斥**。 `(P13.9 / P11.9)`

## H. 自动备份（真 R2 + 真 cron，测不到调度）

- [ ] **19.** 「设置 → 自动备份」开启并选「每 5 小时」→ 应当**立刻备一份**（没有锚点 = 到期），备份列表出现 `cfnote-YYYY-MM-DD-HHMMSS.json`。点「立即备份一次」再来一条。然后去**文件管理**确认这两份**没有**被登记成附件。 `(P14.2)`

## I. 登录限流（⚠️ 放最后，会锁 IP）

- [ ] **20.** ⚠️ **必须用手机流量（关 WiFi）做**，不要用你平时上网那条线路。
  故意输错密码 8 次 → 第 9 次变成「登录尝试过于频繁，请 15 分钟后再试」；**紧接着输正确密码 → 仍然被挡**。然后换回 WiFi，正常密码应当一次登进去。
  > 「正确密码也被挡」才是这条的重点——只有限流拦在密码校验**之前**才做得到，否则限流白做。
  > **为什么不能用自己的线路**：清账只在登录成功时发生，而被锁住就登不进去、也就清不了账，只能等 15 分钟窗口自然过期。
  > 如果第 9 次没被挡：最可能是 Cache API 在这个域名上没工作。那是**设计上的降级方向**（拿不到缓存就放行，免得把主人锁在门外），不是 bug，但要知道。 `(P16.6)`

## J. 窄屏（手机上单独一轮）

- [ ] **21.** 手机打开：侧栏 → 列表 → 正文是**一次只显示一层**的返回栈，顶栏有返回箭头；浏览器前进/后退和刷新能停在同一层。文章列表的置顶/删除是**常驻**的（不是悬浮才出）；文件管理那排 emoji 变成一个「⋯」菜单；AI 对话是全屏覆盖层；编辑器**默认进预览**。 `(P15.1)`

## 已知不在验证范围内的东西

这些是**明确知道没做**，不是漏验：

- **JWT 无法吊销**：7 天有效期、无 `jti`、服务端不存状态，也还没有改密码接口。token 泄露后最长 7 天内仍可用。`(P16.6 记录)`
- **限流按 colo 计数**：换机房就是一份新配额，挡不住分布式爆破。要在请求数那一层挡得用 Cloudflare 控制台的 WAF 速率限制规则（免费套餐就有），那是配置不是代码。`(P16.6 记录)`
- **删父不连子孙进回收站**：P16.1 故意拦住而不是做一半，留给 P16.3。
- **导入不保留目录结构**：P16.4 才做（P15.4 只是让路径进了标题）。
- **深/浅视图、我的私有的审计视图**：P16.2。
- 移动端只定位为「看」，不做离线 / PWA / 冲突合并。`(P15.1 记录)`

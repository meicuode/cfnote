## 为什么不逐批更新每份文档

试过,不行。批次记录写在哪份文档取决于那一批**碰了什么**,而一批往往横跨附件、博客、编辑器三处;
于是同一件事被拆成三段写在三个地方,过几个月谁也说不清哪段是最新的。
现在的规矩是:**决策与取舍统一进 `DESIGN.md` §10,专题文档只维护「这个子系统现在是什么样」**。
